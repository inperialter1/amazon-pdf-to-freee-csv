# Amazon PDF → freee CSV変換ツール

## 概要
Amazonの領収書PDFを読み込み、
freeeにインポート可能なCSVへ変換するツールです。

## 主な機能
- 複数PDF一括対応
- 複数商品抽出対応
- freee形式CSV出力
- 発行者自動抽出
- 勘定科目選択
- 税区分選択

---

## 起動方法

### ① run.bat をダブルクリック

ブラウザが自動で開きます。

---

## 使用方法

1. PDFをアップロード
2. 勘定科目を選択
3. 税区分を選択
4. CSVをダウンロード

---

## 出力形式

### 通常CSV
Amazon PDFから抽出した明細一覧

### freee形式CSV
freeeへインポート可能な形式

---

## 注意事項

- AmazonのPDF形式変更により動作しなくなる場合があります
- 本ツール利用による損害について責任は負いかねます
- ローカル環境で動作するため、データは外部送信されません

---

## 動作環境

- Windows 11
- Python 3.14
- Streamlit
